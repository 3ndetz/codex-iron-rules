# Codex Iron Rules

Durable instructions for completing work and preserving task continuity in Codex sessions.

The canonical rules are in [IRON_RULES.md](IRON_RULES.md). Add their full text to the global Codex `AGENTS.md` so they are available across repositories and sessions. Keep existing instructions intact. Update the installed text when the canonical rules change.

These instructions do not override higher-priority system instructions, security restrictions, or a user's explicit instruction to stop or cancel work.
